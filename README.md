# allsome · 有点东西

作品集交互演示：体验发现作品、阅读制作分享，以及辅助预填、编辑和预览投稿的完整流程。

## 运行

运行 `python3 -m http.server 8080`，打开 `http://localhost:8080/site/`。不要直接双击 HTML。

## 演示范围

- 示例作品、创作者和制作分享；不提供真实工具下载。
- 分享页面使用预置案例填充，不读取输入的仓库链接或调用模型。
- 草稿与点赞仅保存在当前浏览器；没有企业登录或服务器写入。
- 底部“重置体验”可以清除本演示版的本地记录。

## GitHub Pages

在仓库 Settings → Pages 中选择 GitHub Actions。推送 main 后运行部署工作流，网址见 Actions 部署结果。

该仓库只包含独立演示站点，不包含项目工作区、内部资料或服务器凭据。
